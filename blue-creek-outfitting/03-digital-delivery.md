## Ebooks

### Format
- Sell the **PDF** — for a photo-heavy how-to like Trail Riding & Packing (450+
  photos), PDF preserves the exact layout. EPUB reflows and will wreck photo/caption
  placement. **PDF is the right call here.**
- Optionally also offer EPUB later for the text-heavier titles (biography, novel,
  hockey book) where reflow is fine and readers want it on e-readers.

### If you HAVE the source files
Straightforward: export a print-ready PDF, upload to Payhip, set price, publish.
Instant delivery is automatic.

### If you have NO source files (only printed books) — the real blocker
This is the most likely snag, so plan for it:
- **Fastest:** for the first title, a clean **scan-to-PDF** of a physical copy
  (flatbed scanner or a phone scanning app like Adobe Scan) gets you a sellable
  ebook this month. Not beautiful, but real and finishable.
- **Better, later:** have the interior professionally re-typeset from the scans (a
  freelancer on a per-page basis) to get a crisp PDF that also serves POD.
- **Protect the download** — Payhip supports **PDF stamping** (buyer's email
  watermarked on each page), which deters casual sharing without DRM hassle. Turn it
  on for ebooks.

Log which titles have source files vs need scanning — this determines the ebook
order of operations.

## Video (the two DVDs → digital)

### Step 1 — get the video off the disc (digitize)
- If you have the **original edited master files**, skip ripping — use those.
- If only DVDs exist: rip to a clean MP4 (H.264). Tools: HandBrake (free) for a
  DVD you own the rights to. Since you control the content and rights, this is fine.
- Clean up if needed (trim, basic color) in DaVinci Resolve (free) or similar.

### Step 2 — decide: download vs streaming
- **Download (simplest, start here):** sell the MP4 as a digital file, same as an
  ebook. Buyer downloads and keeps it. Payhip does this natively today. **Do this
  first** — it's finishable now.
- **Streaming (later, nicer, more piracy-resistant):** host on **Vimeo** and gate
  access. On Shopify, **Sky Pilot** integrates Vimeo/Wistia so buyers stream rather
  than download. Adds cost + setup — a Phase 2 upgrade, not a launch requirement.

### Step 3 — bundle
- Offer the **book + matching video as a bundle** at a small discount (Trail Riding
  & Packing book + video; Cordillera book + video). Bundles lift average order value
  and are trivial to set up as a third product.
